# 从零到一：Agent 开发实战博客系列（v3.0 搭建式）

> **副标题**：跟着"从零搭 Agent"的拼积木路线，从 LLM 原理到 DeepSeek Harness（DSH）项目实战——最终做出你自己的科研 Agent。
> **目标读者**：计算机本科生。**终极目标**：做出一台（或深度改装出）自己的科研 Agent（文献调研/实验运行/数据分析），前后端分离、后端部署在 Ubuntu 远程主机。
> **结构**：以 Tritium《Build An Agent From Scratch》系列的渐进式搭建结构为骨架（理论 → 最小 Loop → 工具 → 上下文引擎 → 记忆 → Planning → MCP/Skills → DSH 参照 → 企业实战 → 前沿路线），每章统一「理论 → 你的实现 → DSH 参照 → 检验」。

## 每章的阅读法（三遍）

1. **第一遍**：只看正文与图示，跳过代码——建立"它解决什么问题、为什么这样设计"的心智模型；
2. **第二遍**：对照代码片段理解机制（每章"检验"在这里自测）；
3. **第三遍**：打开配套工程还原完整代码（第 9 篇的 `../autoresearcher/`，或 DSH 源码），跑通练习。

- **路线 A（1-2 周）**：装 DSH 试用 + 读第 1、2、8 篇概念部分

- **路线 C（2-3 个月）**：路线 B + Ubuntu 部署 + 自研改造（详见第 10 篇 §5）
