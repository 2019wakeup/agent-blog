## 这系列博客是什么

2026 年的软件开发正在被 **LLM Agent（大模型智能体）** 重塑。**DeepSeek Harness（DSH）** 是其中技术最透明的一个——DeepSeek 开源的 Agent 运行框架，口号是"**一切皆插件**"：你能打开机箱、看到每个齿轮、亲手改一个齿轮。

### 🎯 本系列的终极目标

读完本系列，你将能够**做出一台（或深度改装出）属于自己的科研 Agent**，用于自动化计算机领域科研：

- **能干的事**：文献调研（arXiv/检索/精读）、实验运行与监控（shell/slurm）、数据分析与图表、代码分析与论文辅助写作；
- **深度定制**：基于 DSH 的插件系统，你的工具、你的预设、你的提示词、你的评测集——**别人造的是通用 Agent，你造的是"你的科研流水线"**；
- **架构要求**：**前后端分离**——独立前端 Web 面板（任何机器可访问）+ 独立后端服务（Agent 核心）；
- **部署要求**：**后端跑在你的 Ubuntu 远程主机上**（Docker/systemd 托管，SSH 管理）。

### 三层递进的学习路径

1. **理解**：Agent 的内部构造——函数调用、工具循环、上下文管理、沙箱、多 Agent 编排；
2. **上手 DSH**：读懂 DSH 的插件架构（Cordis）、四个预设、PTC 模式，能改能写；
3. **企业级实战**：完整走通科研 Agent 项目——需求、安全治理、可观测、评测、CI/CD、**前后端分离、Ubuntu 部署**。

"企业级"不是形容词，是这份清单：
✅ 需求明确、边界清晰（做什么、不做什么）
✅ 安全与治理：沙箱、审批流、审计日志
✅ 可观测性：日志、事件流、token 计量与成本控制
✅ 评测体系：工具级单测 + 端到端任务评测，防"悄悄变笨"
✅ CI/CD 与版本化发布：测试门禁、发布渠道、可回滚
✅ **前后端分离**：前端面板 / 后端 API / Agent 核心三层
✅ **Ubuntu 远程部署**：Docker 或 systemd，可远程访问

## 学习路线图（给本科生的建议节奏）

### 路线 A：只想会用（1~2 周）
1. 安装 DSH，切换四个预设感受差异
2. 用 PTC 模式完成一个真实小任务
3. 读第 1、3 篇的概念部分

### 路线 B：理解 + 小实战（4~6 周）★ 推荐
1. 第 1 篇 + 全部练习（跑通 mini_agent）
2. 第 2 篇：跑 LangGraph 示例 + 写一个 MCP Server
3. 第 3 篇：对照源码读 dsh-tools，做 5 个动手实验
4. 第 4 篇：跟随完成科研 Agent（先本地，再上 Ubuntu）

### 路线 C：直达终极目标（2~3 个月）
1. 路线 B 全部
2. 第 4 篇 4.8/4.9：前后端分离 + Ubuntu Docker 部署上线
3. 用创造模式/自研插件，把 Agent 改成"你的科研流水线"
4. 建自己的评测集，持续迭代

## 推荐阅读法（三遍）

1. **第一遍（1 小时/篇）**：只看正文与图示，跳过代码——建立“它解决什么问题、为什么这样设计”的心智模型；
2. **第二遍**：对照代码片段理解机制（检验问题在这里自测）；
3. **第三遍**：打开 `../autoresearcher/` 工程，把片段还原为完整代码，跑通练习。
